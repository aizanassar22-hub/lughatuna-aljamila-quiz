# Lughatuna Aljamila Quiz

**لغتنا الجميلة** — an Arabic, RTL quiz platform concept for Arabic grammar and Quranic parsing exercises.

## First interface prototype
- Responsive Arabic dashboard.
- Tajawal interface typography and Amiri Quranic typography.
- Warm ivory background, sage green accents, and restrained gold details.
- Sample quiz using the question about parsing **ذَوِي** in Al-Baqarah 2:177.

## Current limitations
This is a front-end prototype, not the complete application. It does not yet persist quizzes, create unique quiz URLs, or generate the final WhatsApp share-preview card. Demo controls are illustrative only.

## Run locally
Open `index.html` in a modern browser. Google Fonts are loaded online, with system fallbacks.

## Netlify
Static site; publish from the repository root. No build command is required.
